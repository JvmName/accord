NEGATIVE CONTROL — MUTATION LOG (task 04, plan step 7b)
=======================================================

Why this exists
---------------
Coverage proves code was EXECUTED during capture. It does not prove the
resulting golden ASSERTS anything about it. The only way to tell "captured"
from "actually protected" is to break the server on purpose and check that the
gate goes red.

Procedure (scripted, one mutation at a time)
--------------------------------------------
  1. copy the target file aside
  2. apply the mutation to the UNMODIFIED server
  3. run:  cd server && bun test --isolate test/contract/contract.test.js
  4. restore the file from the copy and verify it is byte-identical

Baseline, unmutated:  7 pass  0 fail
